VORTEXUS 26 — GITHUB PAGES FIX TERBARU

1. Buka folder VORTEXUS26_LENGKAP.
2. COPY semua ISI folder ini ke ROOT repository GitHub Pages.
3. Di ROOT GitHub wajib ada:
   index.html
   login.html
   admin.html
   style.css
   github-pages.js
   logo-vortexus.png
   logo-smkn1.png
   .nojekyll
4. Jangan upload folder VORTEXUS26_LENGKAP sebagai satu folder di dalam repository.
5. GitHub Pages: Settings > Pages > Deploy from branch > main > /(root).
6. Tunggu deployment selesai lalu lakukan Ctrl+Shift+R.

FITUR:
- Upload WAJIB login.
- Jika belum login dan mencoba kirim upload, diarahkan ke login.
- Setelah login dengan jurusan, kembali ke bagian upload.
- Jurusan otomatis mengikuti akun login.
- Filter jurusan dan kategori.
- Pencarian dan random memory.
- Login dan Admin memiliki CSS + logo dari file ROOT agar tidak bergantung pada folder assets.
- Folder assets tetap disertakan sebagai backup.
